# Deduplicate Task Prompt

You are analyzing word-level ASR (Automatic Speech Recognition) output to identify and mark duplicate or repeated words that should be removed.

## Context
The following text contains word-by-word transcription with timestamps. Some words may be repeated due to:
- ASR hallucination
- Speaker stuttering or repetition
- Overlapping audio segments

## Your Task
Review the provided context and identify which duplicate entries should be kept and which should be removed.

For each duplicate sequence, respond with:
- KEEP: [line number(s) to keep]
- REMOVE: [line number(s) to remove]
- REASON: [brief explanation]

## Input Format
Each line: start_time end_time "word"
